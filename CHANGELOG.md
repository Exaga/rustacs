# Changelog

Development history on RUSTACS - Rust Administration & Control Service

Notable changes in development are documented here.

## v2.2.5 - 2026-10-02

- Added multi-server functionality.

## v2.0.3 - 2026-09-05

- Added integrated systemd service management.
- Standardised shared settings through the RUSTACS dot-env file.
- Improved WebRCON command handling and error reporting.
- Added verbose WebRCON diagnostics.
- Added project information and licence options.
- Updated RUSTACS toolset.
- Updated command help and usage documentation.

## v1.5.7 - 2026-08-12

- Added RustDedicated service-management commands.
- Improved WebRCON connection handling.
- Added formatted `serverinfo` output.
- Expanded command-line help and informational options.
- Integrated `rustacs` with the wider RUSTACS toolset.

## v1.0.1 - 2026-06-05

- Initial `rustacs` release.
- Added WebRCON command execution.
- Added RCON settings through the RUSTACS dot-env file.
- Added basic command-line help and status handling.
